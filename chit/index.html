这一页准备怎么工作

额外后端拉取

Hexo 页面渲染后，再从额外接口获取短记录数据，静态站点本身只负责展示。

私密占位保留

私密内容不直接出现在前端，只显示时间点、状态与占位提示，不破坏时间线顺序。

GET 写入预留

后续可以约定简单的 GET 参数格式，先由后端鉴权并写入，再返回前端更新结果。

昨天私密占位

Data Shape

先约定一版简单数据结构

{
  "id": "2026-03-22T12:30:00.000Z",
  "content": "今天继续把博客主线界面收尾。",
  "createdAt": "2026-03-22T12:30:00.000Z",
  "visibility": "public",
  "source": "manual"
}
  • `visibility` 预留 `public | private`
  • `content` 只在公开内容里下发
  • `private` 内容可以只返回占位状态，不返回正文
  • 写入接口后续可约定为 `GET /api/chit/add?content=...&private=1&token=...`
