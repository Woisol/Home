The Very Beginning

鉴于澎湃 OS 越来越严苛的解锁政策，这次设备购置选择了 OPPO 收买后的一加品牌。虽然被 OPPO 收购，但一加至少依然保留着对玩机人的欢迎。以及 3k 不到的 8e 13.2 寸还送笔的过分的竞争力，让人很难不选择这款几乎完美符合本人个人需求的一加平板 2pro。

如果不考虑开放预售那一共 7 天的苦的话（）
以及 16:30 才送到刚好没办法拿去课上耍。

不论如何，到了下课， 第一时间跑去开快递，本来说吃饭好像也没吃😂。
在京东小哥的见证下开箱了新平板，不得不说 13.2 寸第一眼的震撼力非常够，拿惯了 11 寸以后拿起来是有些许的困难。

回到实验室后和 11 寸摆拍了一下。

终于有足够的空间随便（乱）装应用了，进应用商店看到就装，也逛了设置。
注意到 OPPO 账号可以直接登录，头像也没问题，吃惊了一下但是反应过来是在 OPPO 商店已经注册过了。

解锁 bl

新机到手第一件事应该是解锁而不是装应用（），参考 https://magiskcn.com/oneplus-unlock-qualcomm.
html#google_vignette 只需要两条命令，

之后在平板上音量键选择解锁即可。

再次开机，第一屏左上角出现了和 bootloader 一样粗糙的黄字警告，成功开机进入。

clash

装应用不必多说同时进行着，对照手机装就行
装 GitHub 相关的非常慢，下载 clash 也很慢。折腾了一会手机 clash 的局域网访问，但是似乎能连上 clash 却实际连不上网络，无果。
最终还是直接用联盟互传把手机的 clash 传过去了，再加上订阅链接即可。

ksu

由于不了解装 ksu 的流程，趁在实验室有 WI-FI 把系统更新了，然后才发现 Color 并没有米那样手动下载全量包的功能。

差点错失，好在逛酷安逛到了链接，最终依据官网安装即可。
这次已经明确了是 init_boot 了。

字体

解锁的一大需求就来源于换成自己的字体。

网上一搜方法主要是用 DIY 字体替换法替换的
但是本机尝试了两个 DIY 字体没有显示上去，于是放弃。

下一个方向就是使用 magisk 修改。
一加的玩机生态还没有起来……
少数派一篇文章公开了一个模块，尝试用来修改，但是放入所有 fontwx 刷入会无法正常开机（？还是不生效了），具体表现是开机时 ColorOS 界面加载较久，进入系统后能亮屏但全黑。只能用长按电源键的原生安卓菜单重启。
以及找了很久才找到 Magisk 仓库下专门的字体分类，刷入要么不生效要么像上面黑屏
但是尝试刷了数个，包括下载量较高的苹果字体和其它一些，发现对本机一加不管用。

最终在酷安找到了专门针对一加 ColorOS 的模块，修改其中的字体可以得到可用模块，刷入即可。

初次进入系统发现部分中文字体变成了⬜，进入设置把字体改成 Roboton 即可。
较成功实现，但是依然发现 bing 网站等地方会使用默认字体。

桌面

lt 里面可以设置最大行列数，但是找不到地方应用。

一加的玩机资源（）。找了很久，问了客服明确说 pad 系统不支持调整布局，然后才在酷安翻到说平板上被阉割了。

有想法开发个模块，或者直接创始 ColorOS 修改桌面，希望能有时间……
