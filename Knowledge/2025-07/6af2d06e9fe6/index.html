pwsh 优化！

发表于2025-07-20|更新于2025-07-20|Knowledge
|浏览量:

慢慢慢！

不知从什么时候起启动 PowerShell 加载配置文件都要等个 2s，也因此练就了不错的盲打命令能力（bushi），现在必须好好整治一下……

第一个怀疑的自然是配置文件，（又花了时间才）找到了 Documents\WindowsPowerShell\profile.ps1 配置，目前的配置如下：

经过尝试，将 ohmyposh 以及 PSReadLine 注释掉后发现优化不大也就 500ms
询问 DS 使用过 Start-Job -ScriptBlock { Import-Module PSReadLine } 说是异步加载也无果

发现使用 powershell -NoProfile 启动发现快得飞起，但是即便将 profile.ps1 完全注释也无法达到 -Noprofile 的速度

针对此再次询问才知道 wt 会加载多个配置，使用 $PROFILE | Format-List -Force 可以列出，在 C 盘全局的配置中发现了没有被注释掉的 conda 配置（），注释掉后速度大大加快

Windows git alias

在 Linux 上可以很方便地通过 .xxxrc 等设定 git 的 alias，
但是之前的尝试中 Windows 只能设置 Set-Alias -Name g -Value git 指向单一命令而无法使用 gco 等带参命令。

经过 yf 以及群友的推荐，了解了 git-bash + x-cmd 以及 msys2 + fish 的解决方法，
尝试安装 fish 但是发现 msys2 安装目录有点 wsl 的意思甚至还用的 pacman，加上恢复先前配置麻烦，于是中途放弃

最后还是偶然看到可以在 ~/.gitconfig 设置 git 的 alias，
以及尝试在 Linux 上的 .zshrc 找不到 git 相关 alias，结合 zsh 下 git 别名（alias） 和 oh-my-zsh git 插件的故事 才知道不是你自己装的是 oh-my-zsh 自带的😂，
前往 ~/.oh-my-zsh/plugins/git/git.plugin.zsh 即可查看所有的 git alias。

根据 zsh 的 alias 小改动后移植了过来，改动记录如下：

  1. lf 指定为 pull -force 了
  2. st 原为 status，不常用改为 stash 吧且默认 –all
